# AidGrid - AI Disaster Management System

## Overview
AidGrid is an AI-powered disaster management platform that predicts disaster severity, allocates emergency resources, and suggests evacuation routes.

## Features
- Risk Prediction
- Resource Allocation
- Evacuation Planning
- Interactive Dashboard

## Technologies Used
- Python
- Flask
- Scikit-Learn
- NumPy
- NetworkX
- Chart.js

## Run Project

```bash
pip install -r requirements.txt
python backend/app.py
